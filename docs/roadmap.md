# 開發路線

每個里程碑結束時都要：單元測試和 e2e 全過、發一個可以玩的預覽給使用者。

## M0 專案化 ✅

- 原型歸檔到 `prototypes/`。
- 加拉達橋場景移植到模組化架構：邏輯／資料／畫面／介面分開。
- 單元測試（含場景資料檢查）、e2e、CI。

## M1 場景引擎

- 場景切換（加拉達橋 → 卡拉柯伊 → 青旅），進出場景帶著玩家狀態。
- 全域狀態和場景狀態分開：錢、電量、精力、單字、相片、旗標是全域的；spot 狀態是場景的。
- 存檔：睡前日記、入境章（localStorage 先做，之後換正式存檔）。
- 生成角色 sprite（玩家、路人、釣客，各兩張走路影格），取代程式畫的小人。

## M2 移植原型系統

從 `prototypes/liver-red-demo-v3.html` 移植，行為以原型為準，同時補測試：

1. 時間和日期卡（P5 式）、一天三段、睡覺。
2. 手機：App 框架、地圖、訂票、訂房、網購、翻譯、相簿、社群、銀行。
3. 背包：拖曳格子、分層、重量。
4. 股票：A 股模擬（規則見設計摘要）。
5. 屬性、思想櫃、鎖。
6. 開局流程：資金選擇、出門前準備、世界地圖選第一站。

## M3 第一個完整國家

- 用現實路線研究挑一個開局國家（候選：泰國或土耳其），做 2–3 個城市場景、城市之間的交通、簽證和停留天數。
- 內容和價錢全部查證並標日期。
