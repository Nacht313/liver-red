# 豬肝紅冒險・Godot 版：新手說明

## 1. 安裝 Godot

1. 到 https://godotengine.org/download/archive/ 找 **4.7.2**（兩個人一定要裝同一個版本）。
2. Mac 下載後把 `Godot.app` 拖進「應用程式」資料夾；Windows 解壓縮後直接執行。

## 2. 打開專案

1. 打開 Godot，出現「專案管理員」。
2. 按「匯入」，選這個資料夾裡的 `game/project.godot`。
3. 專案出現在清單上，點兩下打開。

## 3. 執行遊戲

打開專案後，按右上角的 **▶**（或按 F5）。
