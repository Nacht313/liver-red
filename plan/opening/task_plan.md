# 計畫：原型開幕移植成可玩版本

## 目標

把 `prototypes/liver-red-demo-v3.html` 的開幕（標題 → 家裡準備 → 出境 → 飛機或陸路 → 泰國入境 → 走出機場）移植到模組化架構，分三輪，每輪結束都能玩。之後才開始做第一個國家。

## 已定案（2026-11-07，使用者）

- 開幕的結束點：**走出機場**（包含 Jay 接機的危險、怎麼進市區；到了市區就接第一個國家）。
- 分三輪做，每輪都能試玩。
- 股票虧損的鎖例外：上限最低可以到 1。其他鎖最低 50。
- **確定之後搬到 Godot**：劇情和數值寫成純資料（可以轉成 JSON，不放函式），遊戲邏輯不碰畫面。
- 第一版地圖畫出整個亞洲，開放的國家逐步增加。

- 沙發衝浪：原型最終版有「Pim 的考核對話」（擲骰降低疑慮），但設計摘要寫「沙發衝浪沒有考核」。第一輪照設計摘要：不做考核。Pim 是否接受由什麼決定，需要策劃定。

## 錯誤紀錄
